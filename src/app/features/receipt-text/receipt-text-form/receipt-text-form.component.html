Instruções e Tags

Você pode adicionar tags especiais no seu texto. Quando o recibo for gerado, o sistema substituirá as tags pelos valores reais do atendimento.

Atenção sobre as Tags:

O sistema só substituirá as tags se forem escritas exatamente iguais (respeitando maiúsculas, minúsculas e sublinhados). Exemplo: não use Valor Total se a tag correta for valor_total.
